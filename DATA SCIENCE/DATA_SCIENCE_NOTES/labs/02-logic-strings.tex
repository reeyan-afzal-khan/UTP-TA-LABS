\textbf{Task 1 --- BMI category flags.}

The source table defines these categories: \(\le 18.4\) Underweight, 18.5--24.9 Normal, 25.0--39.9 Overweight, and \(\ge 40.0\) Obese. Lab 2b's sample output displays one TRUE/FALSE flag for each category, so the following form uses Boolean expressions rather than selection statements (which are introduced in Lab 5).

\begin{lstlisting}[style=dsr]
weight <- as.numeric(readline("Enter weight (kg): "))
height <- as.numeric(readline("Enter height (m): "))

bmi <- weight / (height ^ 2)

underweight <- bmi <= 18.4
normal      <- bmi >= 18.5 & bmi <= 24.9
overweight  <- bmi >= 25.0 & bmi <= 39.9
obese       <- bmi >= 40.0

print(paste("BMI:", bmi))
print(paste("Underweight:", underweight))
print(paste("Normal:", normal))
print(paste("Overweight:", overweight))
print(paste("Obese:", obese))
\end{lstlisting}

\textbf{Task 2 --- Case-insensitive comparison of two strings.}

\begin{lstlisting}[style=dsr]
string1 <- readline("Enter string 1: ")
string2 <- readline("Enter string 2: ")

same <- toupper(string1) == toupper(string2)
print(paste("Both inputs are similar:", same))
\end{lstlisting}

Converting both strings to the same case before comparison makes inputs such as \texttt{test}, \texttt{TEST}, and \texttt{Test} comparable using \texttt{==}.

\textbf{Task 3 --- Uppercase a name and partially display a phone number.}

\begin{lstlisting}[style=dsr]
name <- readline("Enter name: ")
phone <- readline("Enter phone number: ")

name_upper <- toupper(name)
first3 <- substr(phone, 1, 3)
last4 <- substr(phone, nchar(phone) - 3, nchar(phone))

print(paste("Hi,", name_upper,
            ". A verification code has been sent to",
            first3, "-xxxxx", last4))
\end{lstlisting}

The source sample shows the first three and last four digits while masking the middle section. The exact number of mask characters can be adjusted to match the formatting your GA expects.
