\textbf{Goal.} Analyze \texttt{ToothGrowth} correlations and compare three transformations of \texttt{mtcars}.

\textbf{Task 1 --- \texttt{ToothGrowth}: correlation and heatmap.}

Inspect the dataset and select its numeric columns before calculating correlation.

\begin{lstlisting}[style=dsr]
data(ToothGrowth)
str(ToothGrowth)

numeric_tooth <- ToothGrowth[, sapply(ToothGrowth, is.numeric)]

corr_tooth <- cor(numeric_tooth)
print(corr_tooth)

# One heatmap option taught in Lab 9a
install.packages("corrplot")
library(corrplot)
corrplot(corr_tooth, type = "upper")
\end{lstlisting}

Interpret coefficients, not color alone. Note that excluding the categorical \texttt{supp} variable means this simple correlation does not adjust for supplement type.

\textbf{Task 2 --- \texttt{mtcars}: transformation and scaling.}

Inspect the data before applying the three requested methods:

\begin{lstlisting}[style=dsr]
data(mtcars)
str(mtcars)
summary(mtcars)
\end{lstlisting}

Use \texttt{log1p()} because \texttt{mtcars} contains zeros:

\begin{lstlisting}[style=dsr]
# Log transformation that handles zero values
mtcars_log <- log1p(mtcars)

# Standard scaling
mtcars_standard <- as.data.frame(scale(mtcars))

# Min-max scaling
install.packages("caret")
library(caret)

minmax_model <- preProcess(mtcars, method = c("range"))
mtcars_minmax <- predict(minmax_model, mtcars)
\end{lstlisting}

\begin{pitfall}
\texttt{log1p(x)} computes \(\log(1+x)\), so it remains finite at zero. State this choice because it differs from applying \texttt{log()} directly.
\end{pitfall}

Compare the representations using the same variables and the same descriptive functions:

\begin{lstlisting}[style=dsr]
summary(mtcars)
summary(mtcars_log)
summary(mtcars_standard)
summary(mtcars_minmax)
\end{lstlisting}

A concise comparison should include:
\begin{itemize}
  \item the range/center of selected raw columns;
  \item the corresponding summary after log transformation;
  \item the same columns after standard scaling;
  \item the same columns after min--max scaling;
  \item any non-finite values or other issues encountered during transformation.
\end{itemize}
