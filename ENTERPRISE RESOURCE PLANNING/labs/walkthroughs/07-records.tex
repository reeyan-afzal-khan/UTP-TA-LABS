
\begin{labquestion}{1}{Order the five-bike component set}
Create one RFQ per vendor: Ipoh Metal Supply for 5 frames; RubberWheel Co. for 10 tyres; BikeParts Supplier for 5 each of brakes, gears and chains. Use the supplied guide prices and record the document IDs.
\end{labquestion}
\begin{labanswer}\textbf{Inspect the result.} The quantities satisfy one five-bike BOM. If existing stock is used, state the opening balance and adjust the order explicitly.\end{labanswer}

\begin{labquestion}{2}{Record a partial delivery}
In the linked receipt, record only the quantity physically received. If the exercise uses a shortage, retain the remaining quantity as a backorder when prompted.
\end{labquestion}
\begin{labanswer}\textbf{Inspect the result.} Delivered quantity plus outstanding quantity equals the ordered quantity. Compute fill rate using actual receipt quantities, not the order total.\end{labanswer}
