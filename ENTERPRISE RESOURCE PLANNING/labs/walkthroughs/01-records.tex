
\begin{labquestion}{1}{Create one department}
Employees: open Departments and create Sales. Assign its manager after creating the employee record. Save and reopen the department.
\end{labquestion}
\begin{labanswer}\textbf{Inspect the result.} The department record exists once and the manager field points to the intended employee.\end{labanswer}

\begin{labquestion}{2}{Connect the employee and login}
Create the Sales Manager employee and select Sales as the department. If the tutor supplies a login, link that existing user; do not create a duplicate login for the same person. Set app rights through the administrator account.
\end{labquestion}
\begin{labanswer}\textbf{Inspect the result.} Sign in as the assigned Sales user and verify the required Sales actions are available. An employee record alone is not login access.\end{labanswer}
