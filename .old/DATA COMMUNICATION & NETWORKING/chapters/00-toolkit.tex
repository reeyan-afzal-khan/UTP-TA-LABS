\textbf{\href{https://www.wireshark.org/download.html}{Wireshark}} captures and decodes traffic that reaches a selected network interface; use it for packet observations in Lab~1. Huawei eNSP is the simulator used to build and run topologies in Labs~2--9. It starts virtual routers and switches through Oracle VirtualBox, so an installation is ready only after a device boots to its VRP prompt. Follow the versions specified by your instructor to avoid compatibility problems.

\subsection{Quick troubleshooting}
\begin{itemize}
  \item \textbf{Wireshark shows no interfaces:} confirm Npcap was installed,
    then restart Windows and check that the interface is enabled.
  \item \textbf{An eNSP device will not start:} verify that VirtualBox is
    installed and that hardware virtualization is available to the Windows
    environment; confirm the course-specified versions are being used.
  \item \textbf{The console has not reached the VRP prompt:} allow the device
    time to boot. If it remains stuck, record the exact message and ask for
    help before changing several settings at once.
\end{itemize}
