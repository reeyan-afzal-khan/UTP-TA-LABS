Lab 4 shifts from graph search to \term{approximate reasoning}. Fuzzy Logic represents concepts such as ``cold,'' ``warm,'' or ``hot'' using degrees between 0 and 1 rather than forcing every statement to be completely true or false.

\section{From crisp truth to fuzzy membership}

In classical logic, a statement is either false \((0)\) or true \((1)\). In fuzzy logic, a degree can lie anywhere in the interval
\[
0\leq \mu(x)\leq 1.
\]
The Lab 4 example describes ``the water is hot'' as potentially having a truth or membership value such as \(0.7\) rather than only 0 or 1.

\begin{intuition}
Human descriptions often use graded language: somewhat cold, very fast, mostly full. Fuzzy logic turns that kind of gradual description into numerical membership values that a rule system can process.
\end{intuition}

\section{Why fuzzy logic is used}

The handout emphasizes three motivations:
\begin{itemize}
  \item handle uncertainty, imprecision, and approximate reasoning;
  \item support human-like linguistic rules;
  \item build control and decision systems in areas such as control, diagnosis, and pattern recognition.
\end{itemize}

\section{Membership functions in the temperature controller}

The source MATLAB example creates one input, \texttt{Temperature}, over \([0,100]\) and gives it three triangular membership functions: Cold, Warm, and Hot. The output \texttt{FanSpeed} over \([0,10]\) receives Low, Medium, and High membership functions.

\begin{lstlisting}[style=mlmatlab]
fis = mamfis('Name', 'temperatureControl');

fis = addInput(fis, [0 100], 'Name', 'Temperature');
fis = addMF(fis, 'Temperature', 'trimf', [0 0 50], ...
    'Name', 'Cold');
fis = addMF(fis, 'Temperature', 'trimf', [25 50 75], ...
    'Name', 'Warm');
fis = addMF(fis, 'Temperature', 'trimf', [50 100 100], ...
    'Name', 'Hot');

fis = addOutput(fis, [0 10], 'Name', 'FanSpeed');
fis = addMF(fis, 'FanSpeed', 'trimf', [0 0 5], ...
    'Name', 'Low');
fis = addMF(fis, 'FanSpeed', 'trimf', [3 5 7], ...
    'Name', 'Medium');
fis = addMF(fis, 'FanSpeed', 'trimf', [5 10 10], ...
    'Name', 'High');
\end{lstlisting}

The rule list in the handout links the three input terms directly to the corresponding output terms.

\begin{lstlisting}[style=mlmatlab]
ruleList = [
    1 1 1 1;  % IF Cold THEN Low
    2 2 1 1;  % IF Warm THEN Medium
    3 3 1 1   % IF Hot THEN High
];
fis = addRule(fis, ruleList);
\end{lstlisting}

\begin{workedexample}
The source evaluates the controller at a crisp temperature of 70. MATLAB first determines the memberships of 70 in Cold/Warm/Hot, applies the rule base, aggregates the output, and returns one crisp fan-speed value through \texttt{evalfis}.
\end{workedexample}

\section{Mamdani and Sugeno FIS}

Lab 4 distinguishes two types of Fuzzy Inference System.

\begin{mltable}
\begin{tabularx}{\linewidth}{@{}>{\bfseries\leavevmode\color{MLNavy}}p{0.20\linewidth}X@{}}
\toprule
\rowcolor{MLPaleBlue!92}
Type & Laboratory description \\
\midrule
Mamdani & Intuitive and commonly used for control applications. \\
Sugeno & Uses constant or linear output functions and is suitable for optimization and learning. \\
\bottomrule
\end{tabularx}
\end{mltable}

The source Sugeno example creates a \texttt{Speed} input and a \texttt{BrakeForce} output, with Gaussian input membership functions and linear output functions.

\begin{lstlisting}[style=mlmatlab]
fis2 = sugfis('Name', 'speedControl');
fis2 = addInput(fis2, [0 100], 'Name', 'Speed');
fis2 = addOutput(fis2, [0 1], 'Name', 'BrakeForce');

fis2 = addMF(fis2, 'Speed', 'gaussmf', [10 20], 'Name', 'Slow');
fis2 = addMF(fis2, 'Speed', 'gaussmf', [10 80], 'Name', 'Fast');
fis2 = addMF(fis2, 'BrakeForce', 'linear', [0.01 0], 'Name', 'Low');
fis2 = addMF(fis2, 'BrakeForce', 'linear', [-0.01 1], 'Name', 'High');
\end{lstlisting}

\section{ANFIS: Adaptive Neuro-Fuzzy Inference System}

The handout summarizes ANFIS as
\[
\text{ANFIS}=\text{Neural Network learning}+\text{Fuzzy Logic representation}.
\]
It uses a Sugeno-type FIS and learns fuzzy rules and membership-function parameters from input-output data. The handout names a hybrid learning approach combining least squares and gradient descent.

\begin{mltable}
\begin{tabularx}{\linewidth}{@{}>{\bfseries\leavevmode\color{MLNavy}}p{0.25\linewidth}p{0.32\linewidth}X@{}}
\toprule
\rowcolor{MLPaleBlue!92}
Feature & Fuzzy Logic & ANFIS \\
\midrule
Rule definition & Manual & Learned from data \\
Learning capability & No & Yes, through neural-network-style learning \\
Output type & Mamdani or Sugeno & Sugeno only \\
Typical use in handout & Expert-defined systems & Data-driven modeling \\
\bottomrule
\end{tabularx}
\end{mltable}

\begin{keyidea}
Fuzzy Logic is useful when the rule base is supplied by experts. ANFIS is useful when input-output data is available and the fuzzy system should be learned and tuned from that data.
\end{keyidea}

\begin{chapterrecap}
\begin{itemize}

  \item A FIS consists of fuzzification, a rule base, an inference engine, and defuzzification.
  \item Mamdani systems are presented as intuitive control systems; Sugeno systems use constant or linear outputs.
  \item ANFIS combines Sugeno fuzzy inference with data-driven learning.
  \item Lab 4 moves from hand-built membership functions and rules to trained ANFIS models and prediction.
