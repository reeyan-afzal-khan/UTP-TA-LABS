Lab 4 introduces \term{approximate reasoning}: fuzzy logic represents concepts such as ``cold'' or ``hot'' with degrees between 0 and 1.

\section{From crisp truth to fuzzy membership}

In classical logic, a statement is either false \((0)\) or true \((1)\). In fuzzy logic, a degree can lie anywhere in the interval
\[
0\leq \mu(x)\leq 1.
\]
For example, ``the water is hot'' may have membership \(0.7\).

\begin{intuition}
Human descriptions often use graded language: somewhat cold, very fast, mostly full. Fuzzy logic turns that kind of gradual description into numerical membership values that a rule system can process.
\end{intuition}

\section{Why fuzzy logic is used}

Fuzzy logic supports:
\begin{itemize}
  \item handle uncertainty, imprecision, and approximate reasoning;
  \item support human-like linguistic rules;
  \item build decision and control systems for applications such as diagnosis and pattern recognition.
\end{itemize}

\section{Membership functions in the temperature controller}

The MATLAB example creates one input, \texttt{Temperature}, over \([0,100]\) and gives it three triangular membership functions: Cold, Warm, and Hot. The output \texttt{FanSpeed}, over \([0,10]\), receives Low, Medium, and High membership functions.

\begin{lstlisting}[style=mlmatlab]
fis = mamfis('Name', 'temperatureControl');

fis = addInput(fis, [0 100], 'Name', 'Temperature');
fis = addMF(fis, 'Temperature', 'trimf', [0 0 50], ...
    'Name', 'Cold');
fis = addMF(fis, 'Temperature', 'trimf', [25 50 75], ...
    'Name', 'Warm');
fis = addMF(fis, 'Temperature', 'trimf', [50 100 100], ...
    'Name', 'Hot');

fis = addOutput(fis, [0 10], 'Name', 'FanSpeed');
fis = addMF(fis, 'FanSpeed', 'trimf', [0 0 5], ...
    'Name', 'Low');
fis = addMF(fis, 'FanSpeed', 'trimf', [3 5 7], ...
    'Name', 'Medium');
fis = addMF(fis, 'FanSpeed', 'trimf', [5 10 10], ...
    'Name', 'High');
\end{lstlisting}

At a temperature of 70, overlapping memberships activate both Warm and Hot rules; fuzzy inference combines their contributions.

The rule list maps each input term to its corresponding output term.

\begin{lstlisting}[style=mlmatlab]
ruleList = [
    1 1 1 1;  % IF Cold THEN Low
    2 2 1 1;  % IF Warm THEN Medium
    3 3 1 1   % IF Hot THEN High
];
fis = addRule(fis, ruleList);

fanSpeed = evalfis(fis, 70);
fprintf('Fan speed at 70 C: %.2f\n', fanSpeed);
figure;
gensurf(fis);
\end{lstlisting}

\begin{workedexample}
At \(70^\circ\mathrm{C}\), the triangular definitions give
\[
\mu_{Cold}(70)=0,\qquad
\mu_{Warm}(70)=\frac{75-70}{75-50}=0.2,\qquad
\mu_{Hot}(70)=\frac{70-50}{100-50}=0.4.
\]
The Medium and High rules fire at strengths 0.2 and 0.4. Default Mamdani inference with centroid defuzzification produces a fan speed of approximately \(7.16\) on the \([0,10]\) scale.
\end{workedexample}

\section{Mamdani and Sugeno FIS}

Lab 4 distinguishes two types of Fuzzy Inference System.

\begin{mltable}
\begin{tabularx}{\linewidth}{@{}>{\bfseries\leavevmode\color{MLNavy}}p{0.20\linewidth}X@{}}
\toprule
\rowcolor{MLPaleBlue!92}
Type & Laboratory description \\
\midrule
Mamdani & Intuitive and commonly used for control applications. \\
Sugeno & Uses constant or linear output functions and is suitable for optimization and learning. \\
\bottomrule
\end{tabularx}
\end{mltable}

The Sugeno example creates a \texttt{Speed} input and a \texttt{BrakeForce} output, with Gaussian input membership functions and linear output functions.

\begin{lstlisting}[style=mlmatlab]
fis2 = sugfis('Name', 'speedControl');
fis2 = addInput(fis2, [0 100], 'Name', 'Speed');
fis2 = addOutput(fis2, [0 1], 'Name', 'BrakeForce');

fis2 = addMF(fis2, 'Speed', 'gaussmf', [10 20], 'Name', 'Slow');
fis2 = addMF(fis2, 'Speed', 'gaussmf', [10 80], 'Name', 'Fast');
fis2 = addMF(fis2, 'BrakeForce', 'linear', [0.002 0.1], 'Name', 'Low');
fis2 = addMF(fis2, 'BrakeForce', 'linear', [0.006 0.3], 'Name', 'High');

ruleList2 = [
    1 1 1 1;  % IF Speed is Slow THEN BrakeForce is Low
    2 2 1 1   % IF Speed is Fast THEN BrakeForce is High
];
fis2 = addRule(fis2, ruleList2);

brakeForce = evalfis(fis2, 60);
fprintf('Brake force at speed 60: %.3f\n', brakeForce);
\end{lstlisting}

Each Sugeno rule produces a constant or linear value; the FIS returns their firing-strength-weighted average. At speed 60, the Fast rule dominates and the controller returns approximately 0.659. Verify consequence functions rather than relying on labels alone.

\section{ANFIS: Adaptive Neuro-Fuzzy Inference System}

ANFIS can be summarized as
\[
\text{ANFIS}=\text{neural-network learning}+\text{fuzzy-logic representation}.
\]
It uses a Sugeno FIS and learns rule and membership-function parameters from data, commonly through least squares and gradient descent.

\begin{mltable}
\begin{tabularx}{\linewidth}{@{}>{\bfseries\leavevmode\color{MLNavy}}p{0.25\linewidth}p{0.32\linewidth}X@{}}
\toprule
\rowcolor{MLPaleBlue!92}
Feature & Fuzzy Logic & ANFIS \\
\midrule
Rule definition & Manual & Learned from data \\
Learning capability & No & Yes, through neural-network-style learning \\
Output type & Mamdani or Sugeno & Sugeno only \\
Typical use in handout & Expert-defined systems & Data-driven modeling \\
\bottomrule
\end{tabularx}
\end{mltable}

\begin{keyidea}
Use manual fuzzy logic for expert-defined rules and ANFIS when data should determine model parameters.
\end{keyidea}

\section{Training examples in Lab 4}

The examples cover one- and two-input training, prediction, FIS persistence, error analysis, and air-conditioning control.

\begin{lstlisting}[style=mlmatlab]
% Single input
data1 = [0 0; 5 2.5; 10 5; 15 7.5; 20 10];
anfisFIS1 = anfis(data1, 10);

% Two inputs
data2 = [0 0 0; 5 2 2.5; 10 5 5; 15 7 7.5; 20 10 10];
anfisFIS2 = anfis(data2, 20);

% Prediction
inputVal = [12 6];
predictedOutput = evalfis(anfisFIS2, inputVal);
fprintf('Predicted output: %.3f\n', predictedOutput);
\end{lstlisting}

ANFIS interprets the final column as the target. Thus, \texttt{data1} contains one input and one output, whereas \texttt{data2} contains two inputs and one output. A prediction row contains inputs only: \texttt{[12 6]}, without a placeholder for the unknown output.

\begin{pitfall}
Five rows demonstrate the application programming interface (API), not generalization. Evaluate separate validation data before making performance claims.
\end{pitfall}

\begin{chapterrecap}
\begin{itemize}
  \item Fuzzy logic represents degrees of truth between 0 and 1.
  \item A FIS consists of fuzzification, a rule base, an inference engine, and defuzzification.
  \item Mamdani systems aggregate fuzzy outputs; Sugeno systems use constant or linear consequents.
  \item ANFIS combines Sugeno fuzzy inference with data-driven learning.
\end{itemize}
\end{chapterrecap}
