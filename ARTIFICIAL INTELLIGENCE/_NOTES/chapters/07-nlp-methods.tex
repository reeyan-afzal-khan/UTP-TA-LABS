\section{Code 1: Named Entity Recognition (NER) simulation}

The program tokenizes a sentence and matches each token against person, location, and organization dictionaries.

\begin{lstlisting}[style=mlmatlab]
clc; clear;
text = "Barack Obama was born in Hawaii and served as the 44th President of the United States.";

personList = ["Barack Obama"];
locationList = ["Hawaii", "United States"];
organizationList = ["United Nations", "Google", "Microsoft"];

tokens = split(text);
disp("Named Entities Identified:");

for i = 1:length(tokens)
    word = erase(tokens{i}, '.');
    if any(strcmp(word, personList))
        fprintf("Person: %s\n", word);
    elseif any(strcmp(word, locationList))
        fprintf("Location: %s\n", word);
    elseif any(strcmp(word, organizationList))
        fprintf("Organization: %s\n", word);
    end
end
\end{lstlisting}

\begin{pitfall}
The original code splits the sentence into single tokens but stores multi-word entities such as ``Barack Obama'' and ``United States'' as whole dictionary entries. Those entries cannot match a single token in the loop. Consequently, the original output contains only \texttt{Location: Hawaii}. This mismatch shows why representation choices matter.
\end{pitfall}

A rule-based correction searches the normalized sentence for complete dictionary phrases:

\begin{lstlisting}[style=mlmatlab]
cleanText = erasePunctuation(text);
entityGroups = {personList, locationList, organizationList};
groupNames = ["Person", "Location", "Organization"];

for g = 1:numel(entityGroups)
    entries = entityGroups{g};
    for i = 1:numel(entries)
        if contains(lower(cleanText), lower(entries(i)))
            fprintf('%s: %s\n', ...
                char(groupNames(g)), char(entries(i)));
        end
    end
end
\end{lstlisting}

This detects \texttt{Barack Obama}, \texttt{Hawaii}, and \texttt{United States}, but cannot identify entities absent from the dictionaries.

\section{Code 2: summarization by keyword frequency}

The method counts words across the paragraph, scores each sentence by those frequencies, and selects the highest score.

\end{tikzpicture}
\end{mlfigure}

The method is \term{extractive}: the summary is one of the original sentences rather than newly generated prose.

\begin{lstlisting}[style=mlmatlab]
sentences = [
    "AI systems process language."
    "AI systems learn patterns from data."
    "Careful evaluation makes AI systems more reliable."
];

allWords = strings(0, 1);
for i = 1:numel(sentences)
    words = split(lower(erasePunctuation(sentences(i))));
    allWords = [allWords; words(words ~= "")];
end

vocabulary = unique(allWords);
frequency = zeros(size(vocabulary));
for j = 1:numel(vocabulary)
    frequency(j) = sum(allWords == vocabulary(j));
end

scores = zeros(numel(sentences), 1);
for i = 1:numel(sentences)
    words = split(lower(erasePunctuation(sentences(i))));
    for j = 1:numel(words)
        idx = find(vocabulary == words(j), 1);
        if ~isempty(idx)
            scores(i) = scores(i) + frequency(idx);
        end
    end
end

[~, best] = max(scores);
disp("Summary: " + sentences(best));
disp(table(sentences, scores));
\end{lstlisting}

Raw-frequency scoring may favor long sentences and function words; consider stop-word removal or length normalization.

\section{Code 3: grammar correction simulation}

The grammar-correction simulation handles one pattern through string replacement:

\begin{lstlisting}[style=mlmatlab]
inputSentence = "She go to school every day.";
patterns = ["go to school"];
corrections = ["goes to school"];

corrected = inputSentence;
for i = 1:length(patterns)
    corrected = strrep(corrected, patterns(i), corrections(i));
end
disp("Original:  " + inputSentence);
disp("Corrected: " + corrected);
\end{lstlisting}

The program applies a fixed replacement rule rather than inferring grammar.

\section{Code 4: dependency-parsing simulation as part-of-speech (POS) tags}

The example pairs each word in ``The dog chased the cat.'' with a manual tag. Here, \texttt{DET} means determiner, \texttt{NOUN} noun, and \texttt{VERB} verb:
\[
\texttt{DET, NOUN, VERB, DET, NOUN}.
\]

\begin{lstlisting}[style=mlmatlab]
sentence = "The dog chased the cat.";
words = split(erasePunctuation(sentence));
tags = ["DET", "NOUN", "VERB", "DET", "NOUN"];

for i = 1:length(words)
    fprintf("%-7s - %s\n", words{i}, tags{i});
end
\end{lstlisting}

\begin{intuition}
The programmer supplies the tags, so the code demonstrates tagged-text representation rather than automatic parsing.
\end{intuition}

\section{Code 5: simplified Naive Bayes sentiment classification}

Five labeled sentences are converted to binary word features, used to train \texttt{fitcnb}, and tested on ``The product is wonderful.''

\begin{lstlisting}[style=mlmatlab]
texts = [
    "I love this product", ...
    "This is terrible", ...
    "Very happy with the results", ...
    "It is bad and disappointing", ...
    "Absolutely wonderful experience"
];
labels = [1; 0; 1; 0; 1];
bag = ["love", "terrible", "happy", "bad", "wonderful"];

features = zeros(length(texts), length(bag));
for i = 1:length(texts)
    for j = 1:length(bag)
        if contains(lower(texts(i)), bag(j))
            features(i, j) = 1;
        end
    end
end

keep = var(features) > 0;
features = features(:, keep);
activeBag = bag(keep);
Mdl = fitcnb(features, labels, 'DistributionNames', 'kernel');

testText = "The product is wonderful";
testFeatures = zeros(1, numel(activeBag));
for j = 1:numel(activeBag)
    testFeatures(j) = contains(lower(testText), activeBag(j));
end

prediction = predict(Mdl, testFeatures);
if prediction == 1
    disp("Predicted Sentiment: Positive");
else
    disp("Predicted Sentiment: Negative");
end
\end{lstlisting}

For the supplied test sentence, the program reports \texttt{Predicted Sentiment: Positive}.

The same \texttt{keep} mask must be applied to both training and test features. Otherwise, the classifier receives a different number or order of columns during prediction.

\section{Code 6: summarization with TF--IDF}

Lab 7 then uses MATLAB's text-processing objects: \texttt{tokenizedDocument}, \texttt{bagOfWords}, and \texttt{tfidf}. Four sentences are converted into a TF--IDF matrix, sentence scores are computed by summing each row, and the maximum is returned.

\begin{lstlisting}[style=mlmatlab]
text = [
    "Artificial intelligence is a broad field."
    "Machine learning enables systems to learn patterns from data."
    "NLP helps computers process human language."
    "Robotics connects sensing, planning, and action."
];

documents = tokenizedDocument(text);
bag = bagOfWords(documents);
tfidfMatrix = tfidf(bag);
score = sum(tfidfMatrix, 2);
[~, idx] = max(score);
disp("Summary: " + text(idx));
disp(table(text, score));
\end{lstlisting}

For the supplied text, the program selects ``Machine learning enables systems to learn patterns from data.''

Summed TF--IDF may favor sentences with more distinct terms; compare length-normalized scores when sentence lengths differ.

\section{Code 7: rule-based sentiment analysis}

The second sentiment method uses positive and negative word lists rather than a trained classifier.

\begin{lstlisting}[style=mlmatlab]
text = "The scenery was amazing but the final scene was dull.";
positiveWords = ["good", "great", "excellent", "fantastic", ...
                 "amazing", "breathtaking"];
negativeWords = ["bad", "terrible", "awful", "boring", ...
                 "worst", "dull"];

words = lower(split(erasePunctuation(text)));
posCount = sum(ismember(words, positiveWords));
negCount = sum(ismember(words, negativeWords));

if posCount > negCount
    sentiment = "Positive";
elseif negCount > posCount
    sentiment = "Negative";
else
    sentiment = "Neutral";
end
fprintf('Positive=%d, Negative=%d, Result=%s\n', ...
    posCount, negCount, char(sentiment));
\end{lstlisting}

The program returns Positive, Negative, or Neutral according to which count is larger.

\section{Code 8: heuristic language detection}

The language detector defines small keyword lists for English, French, and German. It counts word matches for each list, takes the largest count, and maps the index to a language label. For the supplied French sentence, the program reports French.

\begin{lstlisting}[style=mlmatlab]
text = "Bonjour, comment allez-vous aujourd'hui";
english = ["the", "and", "hello", "good"];
french = ["bonjour", "comment", "vous", "aujourd'hui"];
german = ["hallo", "wie", "geht", "ihnen"];

normalized = lower(erase(text, [",", ".", "!", "?"]));
normalized = replace(normalized, "-", " ");
words = split(normalized);
enCount = sum(ismember(words, english));
frCount = sum(ismember(words, french));
deCount = sum(ismember(words, german));

counts = [enCount, frCount, deCount];
languages = ["English", "French", "German"];
[bestCount, idx] = max(counts);
if bestCount == 0
    result = "Unknown";
elseif sum(counts == bestCount) > 1
    result = "Ambiguous";
else
    result = languages(idx);
end
disp("Detected language: " + result);
\end{lstlisting}

The zero-match and tie checks prevent the program from reporting English merely because it occupies the first array position.

\section{Code 9: keyword extraction}

The final example tokenizes a paragraph, removes stop words and punctuation, builds a bag-of-words model, sorts vocabulary counts in descending order, and returns the top five words.

\begin{lstlisting}[style=mlmatlab]
text = "Data science involves extracting useful insights from data. " + ...
       "Data analysis and machine learning support better decisions.";
document = tokenizedDocument(text);
document = removeStopWords(document);
document = erasePunctuation(document);

bow = bagOfWords(document);
[sortedCounts, sortedIndex] = sort(bow.Counts, 'descend');
sortedWords = bow.Vocabulary(sortedIndex);
keywords = sortedWords(1:min(5, end));
keywordCounts = sortedCounts(1:min(5, end));
disp(table(keywords', keywordCounts', ...
    'VariableNames', {'Keyword', 'Count'}));
\end{lstlisting}

For the supplied paragraph, the output includes the terms Data, science, involves, extracting, and insights.
