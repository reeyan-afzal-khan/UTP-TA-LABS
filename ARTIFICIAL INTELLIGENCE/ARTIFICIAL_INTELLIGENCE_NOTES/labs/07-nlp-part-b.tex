\labsection{7}{Natural Language Processing --- Part B}{sec:lab07-nlp-b}

\begin{labproject}{Nine compact NLP pipelines in MATLAB}
\textbf{Coverage.} NER simulation, frequency summarization, grammar correction, POS-style tagging, Naive Bayes sentiment, TF--IDF summarization, rule-based sentiment, language detection, and keyword extraction.\\
\textbf{Goal.} Compare hand-written rules, statistical text representations, and a simple trained classifier.

\begin{labmode}
The source intentionally uses small examples. Preserve the supplied sentences and output screenshots first; extend only after the baseline result matches.
\end{labmode}

\medskip\noindent\textbf{Part A --- Rule/dictionary pipelines.}\par
Run Codes 1, 3, 4, 7, and 8. For each one, list the dictionary, pattern, tag list, or lexicon that the programmer supplied manually.

\medskip\noindent\textbf{Part B --- Summarization pipelines.}\par
Run Code 2 and Code 6 on their supplied text. Record the selected sentence from each method and explain the scoring signal: raw frequency versus TF--IDF.

\medskip\noindent\textbf{Part C --- Learned sentiment classifier.}\par
Run Code 5 and reproduce the source prediction for ``The product is wonderful.'' Print the binary feature row for the test sentence before prediction.

\medskip\noindent\textbf{Part D --- Keyword extraction.}\par
Run Code 9 and record the top five keywords after stop-word and punctuation removal.

\begin{tryit}
Improve the NER simulation so that it can detect at least one multi-word dictionary entry while keeping the exercise rule-based. Show the original output and the improved output side by side.
\end{tryit}
\end{labproject}

\begin{labdeliverable}
Submit one MATLAB live script containing Codes 1--9, the requested outputs, and a comparison table classifying each method as rule/dictionary based, statistics based, or trained classifier based.
\end{labdeliverable}
