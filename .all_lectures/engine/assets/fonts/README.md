# Fonts

The books' own typefaces, so the videos match the PDFs:

* **Source Sans 3** (text) and **Source Code Pro** (code), by Adobe, copied from the MiKTeX
  `sourcesanspro` / `sourcecodepro` packages.

Both are released under the SIL Open Font License 1.1 (https://openfontlicense.org), which allows them to
be bundled and redistributed with software. The engine loads them at render time; nothing is installed.
