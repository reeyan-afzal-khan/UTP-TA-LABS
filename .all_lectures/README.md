# Lecture videos

Narrated, animated lectures made from the course books: one video per chapter and per lab, named after its
LaTeX file, at 1080p and 60 fps, with subtitles. They are generated by the engine in [`engine/`](engine)
from the same LaTeX as the PDFs in [`.all_pdfs`](../.all_pdfs), so they follow the books when the books
change.

```bash
python .all_lectures/engine/lecture.py build ADS ch1
```

How to build, edit and re-voice a lecture: [`engine/README.md`](engine/README.md).

## Layout

```text
.all_lectures/
  engine/                          the video engine (Manim Community)
  <course-slug>/
    chapters/<file>.mp4            a chapter lecture, named after chapters/<file>.tex
    chapters/<file>.srt            its subtitles
    chapters/<file>.script.yaml    what it shows and says, editable
    labs/<file>.mp4 ...            the same for each lab sheet
    voice/<chapters|labs>/<file>/  your own recordings, one file per cue (optional)
```
