\chapter{VLAN Configuration: Access, Trunk, and Hybrid Ports}\label{ch:vlan}
\chapterguide{Ethernet switch configuration and Eth-Trunk/LACP concepts from Lab 7.}{Create VLANs, bind access ports, turn the inter-switch Eth-Trunk into a VLAN trunk, configure hybrid ports and PVID behavior, and verify same-VLAN and controlled cross-VLAN communication.}

\section{Purpose of VLANs}
VLANs create separate Layer-2 broadcast domains on shared switches. Hosts in different VLANs remain isolated unless the design deliberately connects them.

\sourceimage[0.88\linewidth]{VLAN topology from the supplied Lab 8 slide}{vlan-topology.png}

\section{Three port behaviors used in the exercise}
\begin{tabularx}{\linewidth}{>{\bfseries}p{0.23\linewidth}X}
\toprule
Port type & Role in the supplied lab\\\midrule
Access & Connects an untagged host to one VLAN.\\
Trunk & Carries multiple VLANs between switches.\\
Hybrid & Controls tagging per VLAN and classifies untagged ingress by PVID.\\\bottomrule
\end{tabularx}

\section{Step 1: build the inter-switch Eth-Trunk}
Build static-LACP Eth-Trunk 1 with G0/0/9 and G0/0/10. The source shows both physical-interface membership and \cmd{trunkport} from the Eth-Trunk view.
\begin{lstlisting}[style=dcnterminal]
[S1] interface Eth-Trunk 1
[S1-Eth-Trunk1] mode lacp
[S1] interface GigabitEthernet 0/0/9
[S1-GigabitEthernet0/0/9] eth-trunk 1
[S1] interface GigabitEthernet 0/0/10
[S1-GigabitEthernet0/0/10] eth-trunk 1

[S2] interface Eth-Trunk 1
[S2-Eth-Trunk1] mode lacp
[S2-Eth-Trunk1] trunkport GigabitEthernet 0/0/9
[S2-Eth-Trunk1] trunkport GigabitEthernet 0/0/10
\end{lstlisting}

\section{Step 2: make Eth-Trunk 1 a VLAN trunk}
\begin{lstlisting}[style=dcnterminal]
[S1] interface Eth-Trunk 1
[S1-Eth-Trunk1] port link-type trunk
[S1-Eth-Trunk1] port trunk allow-pass vlan all

[S2] interface Eth-Trunk 1
[S2-Eth-Trunk1] port link-type trunk
[S2-Eth-Trunk1] port trunk allow-pass vlan all
\end{lstlisting}

\begin{keyidea}
Eth-Trunk aggregates links; trunk mode carries VLANs. These are separate functions on the same logical interface.
\end{keyidea}

\section{Step 3: create VLANs and bind access interfaces}
The lab demonstrates two Huawei VRP configuration styles.

On S1, G0/0/13 is associated with VLAN 3 and G0/0/1 with VLAN 4:
\begin{lstlisting}[style=dcnterminal]

[S1-GigabitEthernet0/0/13] port link-type access

[S1-GigabitEthernet0/0/1] port link-type access

\section{Step 5: change selected ports to hybrid mode}
Hybrid ports then deliver VLAN 2 and VLAN 4 traffic untagged to selected devices.
\begin{lstlisting}[style=dcnterminal]
[S1] interface GigabitEthernet 0/0/1
[S1-GigabitEthernet0/0/1] port link-type hybrid
[S1-GigabitEthernet0/0/1] port hybrid untagged vlan 2 4
[S1-GigabitEthernet0/0/1] port hybrid pvid vlan 4

[S2] interface GigabitEthernet 0/0/3
[S2-GigabitEthernet0/0/3] port link-type hybrid
[S2-GigabitEthernet0/0/3] port hybrid untagged vlan 2 4
[S2-GigabitEthernet0/0/3] port hybrid pvid vlan 4

[S2] interface GigabitEthernet 0/0/6
[S2-GigabitEthernet0/0/6] port link-type hybrid
[S2-GigabitEthernet0/0/6] port hybrid untagged vlan 2 4
[S2-GigabitEthernet0/0/6] port hybrid pvid vlan 2
\end{lstlisting}

\section{PVID and untagged behavior}
The commands are complementary:
\begin{itemize}
\item \cmd{port hybrid pvid vlan <id>} assigns a VLAN classification to untagged frames received from the host.
\item \cmd{port hybrid untagged vlan 2 4} permits frames from the listed VLANs to leave that host-facing port without a VLAN tag.
\end{itemize}
Retest reachability: the selected VLAN-2 and VLAN-4 hosts should communicate, while the VLAN-3 host remains isolated.

\begin{conceptmap}
\textbf{Ingress from host, no tag} $\rightarrow$ classify using the port PVID.\\
\textbf{Frame inside the switch} $\rightarrow$ VLAN membership is tracked logically.\\
\textbf{Egress toward selected host} $\rightarrow$ listed hybrid VLANs can be sent untagged.
\end{conceptmap}

\section{Troubleshooting VLAN reachability}
\begin{netsteps}
\item Check the host IP/subnet first; VLAN experiments still require correct Layer-3 addressing on the endpoints.
\item Confirm the host-facing port link type and VLAN/PVID assignment.
\item Confirm the VLAN exists on both switches where required.
\item Confirm Eth-Trunk 1 is up and is configured as a trunk carrying the relevant VLANs.
\item For hybrid ports, inspect both the PVID and the tagged/untagged VLAN lists.
\item Use ping results as evidence only after the switch configuration matches the intended VLAN path.
\end{netsteps}
