! ============================================================
! Lab 7 --- Eth-Trunk in STATIC LACP mode
! ============================================================

system-view

interface Eth-Trunk 1
 undo mode manual load-balance
 mode lacp-static
quit

! ---------- Priorities: two settings, two different jobs ----------
!
! SYSTEM priority decides WHICH SWITCH selects the active links.
! Lower wins; ties break on system MAC. Only one end gets to choose,
! otherwise the two could disagree.
lacp priority 100

interface Eth-Trunk 1
 ! More members than active links -- the rest wait as backups.
 max active-linknumber 2
quit

! PORT priority is then used BY THAT SWITCH to rank candidate ports.
! Lower is preferred.
!
! Setting port priorities on the switch that LOST the system-priority
! election has no effect. Students often mistake this for a broken
! configuration.
interface GigabitEthernet 0/0/1
 lacp priority 100
quit
interface GigabitEthernet 0/0/2
 lacp priority 200
quit

quit
save

! ---------- Verify ----------
! display eth-trunk 1
!   Members show Selected / Unselected. Selected count should match
!   max active-linknumber.
!
! display lacp statistics eth-trunk 1
!   LACP frames sent and received -- proves negotiation is happening.

! ---------- Why this is safer ----------
! Each end sends LACP frames announcing system ID, port priority, and key.
! A member joins the bundle ONLY when both ends agree it should.
!
! Miscabling now produces a port that stays out of the bundle -- a fault
! that is visible, contained, and safe, instead of a broadcast storm.

! ---------- Both ends must run the same mode ----------
! Manual on one end and LACP on the other leaves members unselected.
