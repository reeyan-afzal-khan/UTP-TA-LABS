! ============================================================
! Lab 3 --- R1 static routing
! Add the routes in stages so you can observe each failure mode.
! ============================================================

system-view
sysname R1

interface GigabitEthernet 0/0/1
 ip address 192.168.1.1 24
 undo shutdown
quit

interface GigabitEthernet 0/0/0
 ip address 10.0.12.1 30
 undo shutdown
quit

interface GigabitEthernet 0/0/2
 ip address 10.0.13.1 30
 undo shutdown
quit

! ---------- STOP. Verify before adding routes. ----------
! display ip routing-table
!   Every entry should be Direct. Record this output.
!   Ping PC1 -> PC3 now; it MUST fail. Understanding why is the lab.

! ---------- Stage 1: primary route to LAN 3 ----------
! Destination is a NETWORK address (host bits zeroed), not a host.
ip route-static 192.168.3.0 24 10.0.12.2

! ---------- STOP. Ping again. ----------
! It still fails -- R3 has no route back, so the REPLY is dropped.
! Add the mirror route on R3 before continuing.

! ---------- Stage 2: backup route via R3 direct link ----------
! Higher preference number = less preferred. Static defaults to 60.
ip route-static 192.168.3.0 24 10.0.13.3 preference 100

quit
save

! ---------- Verify ----------
! display ip routing-table protocol static
!   Only the preference-60 route should be active.
!   The backup is held in reserve, not installed.
!
! Failover test:
!   1. Start a long ping from PC1 to PC3
!   2. interface GigabitEthernet 0/0/0 / shutdown
!   3. display ip routing-table protocol static  -> backup now installed
!   4. Count the lost pings. It will not be zero -- the router must first
!      decide the next hop is unreachable.
