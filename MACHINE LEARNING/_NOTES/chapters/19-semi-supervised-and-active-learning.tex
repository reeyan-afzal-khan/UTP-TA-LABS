Stages 3 and 4 showed the two clean endpoints: labels for the supervised branch and no supplied labels for the unsupervised branch. Real projects often sit between them. In ordinary supervised learning, every training row has a label. In many real projects, raw examples are plentiful but labels are expensive. A doctor may need to label scans, an engineer may need to inspect machine failures, or a legal expert may need to categorize documents.

\term{Semi-supervised learning} uses a small labeled dataset together with a larger unlabeled dataset. \term{Active learning} asks a human to label the examples that would be most useful.

\begin{firstread}
Think of a box of photographs where only a few have names written on the back. Semi-supervised learning uses the named photos for meaning and the unnamed photos for structure. Active learning chooses which unnamed photo would be most useful to ask a person about next.
\end{firstread}

\section{The data setting}

Let
\[
  \mathcal{D}_L=\{(\bm{x}_i,y_i)\}_{i=1}^{n_L}
\]
be the labeled data and
\[
  \mathcal{D}_U=\{\bm{x}_j\}_{j=1}^{n_U}
\]
be the unlabeled data, usually with $n_U\gg n_L$.

Unlabeled data can show where observations are concentrated, which examples are similar, and where natural groups may exist. It cannot by itself reveal the meaning of a class label.

\begin{intuition}
Imagine a map with only a few towns named. The unnamed dots still show where settlements are clustered. The labeled towns provide meaning; the unlabeled dots provide structure.
\end{intuition}

\section{When unlabeled data can help}

Semi-supervised methods rely on assumptions such as:

\begin{itemize}
  \item nearby observations are likely to share a label;
  \item observations in the same dense region are likely to share a label;
  \item the decision boundary should pass through low-density areas rather than cutting through a cluster.
\end{itemize}

These assumptions may be wrong. Two nearby customers can have different outcomes, or a cluster can contain several classes. Unlabeled data helps only when its structure relates to the label.

\section{Self-training and pseudo-labeling}

Self-training is the simplest semi-supervised approach.

\begin{mlsteps}
  \item Train a supervised model on the labeled data.
  \item Predict labels and probabilities for the unlabeled data.
  \item Keep only predictions with confidence above a strict threshold.
  \item Add those pseudo-labeled examples to the training set, usually with lower weight.
  \item Retrain the model and repeat for a limited number of rounds.
\end{mlsteps}

\begin{workedexample}
A classifier has 1,000 labeled messages and 20,000 unlabeled messages. It assigns 1,500 unlabeled messages a predicted class probability above 0.98. Those high-confidence predictions are added as temporary labels. The model is retrained, but final evaluation still uses a genuinely labeled validation and test set.
\end{workedexample}

\begin{pitfall}
A confidently wrong model can teach itself the wrong answer. Pseudo-labeling should use conservative thresholds, class-balance checks, limited rounds, and validation against human labels.
\end{pitfall}

\section{Graph-based label propagation}

A graph-based method treats each observation as a node. Similar observations are joined by stronger edges. Labels then spread from labeled nodes to nearby unlabeled nodes.

This works well when similarity is meaningful and clusters line up with classes. It can fail when the graph connects unlike observations or when feature scaling is poor.

\section{Co-training}

Co-training uses two different views of the same observation. For example, a webpage may have text content and link information. Two models are trained separately; each adds high-confidence labels for the other.

The method is most plausible when both views contain useful information and make partly independent errors. It is not appropriate when the two views are nearly identical.

\section{Active learning}

Active learning spends a labeling budget carefully. Instead of labeling random examples, the model selects examples expected to teach it the most.

Common selection strategies include:

\begin{mltable}
\begin{tabularx}{\linewidth}{@{}>{\bfseries\leavevmode\color{MLNavy}}p{0.26\linewidth}X@{}}
\toprule
\rowcolor{MLPaleBlue!92}
Selection strategy & Which examples it chooses \\
\midrule
Uncertainty sampling & Examples whose predicted probabilities are closest to a tie. \\
Query by disagreement & Examples on which several models disagree. \\
Diversity sampling & Uncertain examples that also cover different regions of the feature space. \\
Expected impact & Examples whose labels are estimated to improve the model most or reduce decision cost. \\
\bottomrule
\end{tabularx}
\end{mltable}

\section{The active learning loop, drawn}

Active learning inverts the usual arrangement. Instead of being handed labels, the model asks for the ones it most needs.

\node[st,below=of score] (pick) {3. Select the most uncertain examples};

\begin{analogy}
A student revising for an exam has limited time. The inefficient approach is to reread the whole textbook. The efficient approach is to attempt practice questions, notice which topics produce hesitation, and study only those. Active learning is a model doing exactly that: spending its scarce labeling budget on the examples that confuse it most.
\end{analogy}

\section{A safe practical workflow}

\begin{mlsteps}
  \item Create fixed, human-labeled validation and test sets before using unlabeled data.
  \item Train a supervised baseline using only the labeled training set.
  \item Inspect whether similarity or cluster structure appears connected to the label.
  \item Add one semi-supervised or active-learning method at a time.
  \item Compare against the labeled-only baseline using the same evaluation protocol.
  \item Review performance by class and subgroup, not only overall average performance.
  \item Keep a record of which labels came from humans and which came from the model.
\end{mlsteps}

\begin{keyidea}
Unlabeled data provides structure, not truth. Human labels remain the source of meaning and the basis of fair evaluation.
\end{keyidea}

\begin{chapterrecap}
\begin{itemize}
  \item Semi-supervised learning combines a small labeled set with a larger unlabeled set.
  \item Pseudo-labeling adds only high-confidence model predictions and must be checked for error reinforcement.
  \item Graph methods spread labels through similarity connections.
  \item Active learning asks humans to label examples that are uncertain, disputed, diverse, or high impact.
  \item Final validation and testing must use genuine human labels.
\end{itemize}
\end{chapterrecap}
