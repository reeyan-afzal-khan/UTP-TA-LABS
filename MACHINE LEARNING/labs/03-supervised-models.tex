\labpart{Part A --- KNN versus Gaussian naive Bayes}

\begin{labquestion}{2}{Split the breast-cancer table}
Two classifiers built on very different ideas are about to meet. KNN looks at the $k$ nearest training tumors, in standardized distance, and takes a vote. Gaussian naive Bayes assumes each feature is bell-shaped within each class and multiplies per-feature probabilities together. Both use this split.
\end{labquestion}
\begin{labanswer}
\input{labs/visuals/03-trace}
\lstinputlisting[style=utppython,firstline=39,lastline=46]{all_experiments/lab03_supervised_models_worked.py}

\textbf{What it means.} This is Lab~2's split: same seed, same fraction. So scores here and in Question~11 are computed on the same 143 rows.
\end{labanswer}

\begin{labquestion}{3}{Choose $k$ by cross-validation}
$k$ is a hyperparameter, so it is chosen by cross-validation inside the training partition. Small $k$ follows every local quirk (low bias, high variance), and large $k$ smooths everything (high bias, low variance).
\end{labquestion}
\begin{labanswer}

Anything from 7 to 21 is fine, and $k=1$ is clearly worse because a single neighbor is easily fooled by one unusual tumor. Choosing $k$ by training accuracy would pick $k=1$ every time, since every row is its own nearest neighbor.

\labpart{Part C --- Random forest versus gradient boosting}

\begin{labquestion}{9}{Compare forest and boosting on Ames Housing}
Ames Housing has 79 feature columns of mixed types describing houses, and a sale price that is strongly right-skewed, so $\log(1+\text{price})$ is modeled. A random forest averages many deep trees grown on different bootstrap samples. Gradient boosting grows shallow trees one after another, each fitting what the previous ones got wrong. Both are scored on the same three folds. This cell takes the longest.
\end{labquestion}

\labpart{Part D --- Support vector machines: two dials and a kernel}

\begin{labquestion}{11}{Tune an SVM}
An SVM looks for the boundary with the widest margin between the classes. It measures margins in feature units, so the scaler goes inside the pipeline and is refitted in every fold. $C$ is how strictly training mistakes are punished. The kernel decides the \emph{shape} of boundary allowed. For the RBF kernel, $\gamma$ sets how far each training point's influence reaches.
\end{labquestion}
\begin{labanswer}
\lstinputlisting[style=utppython,firstline=248,lastline=271]{all_experiments/lab03_supervised_models_worked.py}
\begin{refoutput}
\begin{lstlisting}[style=utpterminal]
best parameters: {'model__C': 10, 'model__gamma': 0.01, 'model__kernel': 'rbf'}
cross-validated ROC AUC: 0.995
test accuracy: 0.979
test ROC AUC: 0.997
\end{lstlisting}
\end{refoutput}

\textbf{What it means.} The search tries 24 combinations over 5 folds, and the winner is tested once. These are the same rows as KNN's 0.986 and naive Bayes's 0.992 in Question~4, so the comparison is fair, though those two scores have already been looked at.
\end{labanswer}

\begin{labquestion}{12}{Map the two dials}
A heat map of the RBF results shows how the two dials interact; each cell is the cross-validated ROC AUC for one $(C,\gamma)$ pair. Beside it, the two kernels refitted on radius and texture show the shape of boundary each is allowed to draw.
\end{labquestion}
\begin{labanswer}
\lstinputlisting[style=utppython,firstline=273,lastline=303]{all_experiments/lab03_supervised_models_worked.py}

\textbf{What it means.} All twelve cells lie between 0.978 and 0.995 (Chapter~\ref{ch:svm} prints them). The weakest cell has the smallest $C$ with the largest $\gamma$. The linear kernel draws one straight line, and the RBF kernel with $\gamma=1$ bends around groups of points and carves out islands. On this data the extra flexibility buys little: once scaled, the classes are close to linearly separable.
\end{labanswer}
