\labpart{Part B --- Feature engineering}

\begin{labquestion}{5}{Engineer four new columns}
Feature engineering means building inputs the model cannot see on its own. \texttt{FamilySize} and \texttt{IsAlone} come from two counts, \texttt{Title} is pulled out of the name with a regular expression, and \texttt{LogFare} tames a long right tail. Every one is built from information known before the outcome, which is the test each new feature must pass.
\end{labquestion}

\begin{labquestion}{11}{Compare feature sets, and see leakage}
Three feature sets are compared with the same ridge regression. \texttt{SelectKBest} keeps the ten columns most correlated with the grade, and the lasso penalty shrinks weak coefficients to zero and so selects on its own. Both selectors sit \emph{inside} the pipeline, after encoding, so they only ever see training rows. The fourth run adds \texttt{G2} back on purpose, to show what leakage looks like.
\end{labquestion}
\begin{labanswer}
\lstinputlisting[style=utppython,firstline=146,lastline=175]{all_experiments/lab01_features_worked.py}
\begin{refoutput}
\begin{lstlisting}[style=utpterminal]
all 30 features                  validation MAE = 2.181 grade points
SelectKBest, k=10                validation MAE = 2.139 grade points
lasso (selects itself)           validation MAE = 2.077 grade points
all 30 + G2 (leakage)            validation MAE = 0.762 grade points
\end{lstlisting}
\end{refoutput}

\textbf{What it means.} Ten columns do about as well as thirty, so most of the table is noise for this task, and a selector inside the pipeline does no harm and a little good. Always guessing the training mean scores 2.37, which is the true scale of these gains. The leaked column cuts the error by two thirds. That looks like a triumph and is a broken experiment, because \texttt{G2} does not exist at enrolment.
\end{labanswer}

\begin{expectedfindings}
\textbf{Warm-up.} Passenger 1: \texttt{FamilySize} 2, \texttt{IsAlone} 0, \texttt{Title} Mr, \texttt{LogFare} 2.11. For the two gaps, 100 beats 5 in raw units; after scaling they are $100/351.9=0.28$ and $5/4.3=1.16$, so the second dominates.
\begin{enumerate}
  \item It stays at 0.872. Fare and family size are already in the model, so the ratio brings nothing new.
  \item It also stays at 0.872 to three decimals. Medians and scales from 891 rows barely differ from those of 668 rows, so this leak does little harm on this table. That does not make it safe: the same habit, applied to selection on all the labels, made pure noise score 0.80. Keep the pipeline, because you cannot know in advance which case you are in.
  \item With \texttt{G1} the MAE is 1.246 and with \texttt{G2} it is 0.762, against 2.181 with neither. The later grade is closer in time to \texttt{G3}, so it says more. Both are leaks at enrolment; both would be fair inputs for a prediction made later in the year.
  \item \texttt{alpha} 0.01 keeps 43 columns, MAE 2.159. \texttt{alpha} 0.1 keeps 19, MAE 2.077. \texttt{alpha} 0.5 keeps 4, MAE 2.151. Four columns do almost as well as forty-three.
\end{enumerate}
\end{expectedfindings}
