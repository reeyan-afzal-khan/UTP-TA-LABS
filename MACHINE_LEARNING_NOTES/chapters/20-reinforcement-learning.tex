The final learning signal changes more radically. Supervised learning receives target answers, unsupervised learning receives no external answer key, and reinforcement learning receives rewards after actions. Reinforcement learning (RL) studies decisions that affect what happens next. Instead of receiving the correct answer for every action, an agent receives rewards and must discover which behavior produces the best long-term outcome.

\begin{firstread}
Translate the vocabulary before reading the equations: the \term{agent} is the decision-maker, the \term{state} is the current situation, an \term{action} is a choice, and the \term{reward} is feedback. The difficult part is that a choice can change later situations, so the best immediate reward may not produce the best long-term result.
\end{firstread}

\end{optionaltopic}

\section{The agent-environment loop}

At time $t$:

\begin{mlsteps}
  \item The agent observes a state $s_t$.
  \item It chooses an action $a_t$.
  \item The environment returns a reward $r_{t+1}$ and a new state $s_{t+1}$.
  \item The agent updates what it believes about the action.
\end{mlsteps}

\begin{workedexample}
A warehouse robot observes its location and remaining battery. It chooses to move, wait, or recharge. It may receive a small cost for time, a larger cost for collisions, and a positive reward for delivering an item. A good policy must consider future consequences, not only the next reward.
\end{workedexample}

\section{A simpler case: multi-armed bandits}

A multi-armed bandit has several actions but no changing state. Each action gives an uncertain reward. The goal is to discover and repeatedly choose the most rewarding action.

This creates the central RL problem:

\begin{description}[leftmargin=1.35in,style=nextline]
  \item[Exploration] Try uncertain actions to learn more about them.
  \item[Exploitation] Choose the action currently believed to be best.
\end{description}

An $\varepsilon$-greedy strategy explores with probability $\varepsilon$ and otherwise exploits.

\section{Markov decision processes}

A classical RL problem is often written as a Markov decision process (MDP) with:

\begin{itemize}
  \item a set of states $\mathcal{S}$;
  \item a set of actions $\mathcal{A}$;
  \item transition probabilities $P(s'\given s,a)$;
  \item a reward rule;
  \item a discount factor $\gamma\in[0,1)$.
\end{itemize}

The Markov assumption says the current state contains the information needed to predict the next state distribution. The full distant past does not need to be stored separately.

\section{Return and discounting}

The return from time $t$ is the discounted sum of future rewards:
\[
  G_t=r_{t+1}+\gamma r_{t+2}+\gamma^2r_{t+3}+\cdots.
\]

The discount factor $\gamma$ controls how much future rewards matter.

\begin{itemize}
  \item Small $\gamma$: favor immediate rewards.
  \item Large $\gamma$: value long-term rewards more strongly.
\end{itemize}

\begin{workedexample}
Suppose future rewards are $5$, $4$, and $3$, with $\gamma=0.9$. Then
\[
G_t=5+0.9(4)+0.9^2(3)=11.03.
\]
The later rewards count, but each is discounted.
\end{workedexample}

\section{Policies and value functions}

A \term{policy} $\pi(a\given s)$ describes how the agent chooses actions in each state.

The state-value function is
\[
  V^{\pi}(s)=\mathbb{E}_{\pi}[G_t\given s_t=s],
\]
the expected return from state $s$ while following policy $\pi$.

The action-value function is
\[
  Q^{\pi}(s,a)=\mathbb{E}_{\pi}[G_t\given s_t=s,a_t=a],
\]
the expected return from taking action $a$ in state $s$ and then following $\pi$.

\begin{intuition}
$V(s)$ asks, ``How good is this situation?'' $Q(s,a)$ asks, ``How good is this particular move from this situation?''
\end{intuition}

\section{The Bellman idea}

A long-term value can be broken into two parts:

\[
\text{value now}=\text{reward next}+\text{discounted value later}.
\]

For an optimal action-value function,
\[
Q^*(s,a)=\mathbb{E}\left[r_{t+1}+\gamma\max_{a'}Q^*(s_{t+1},a')\mid s_t=s,a_t=a\right].
\]
This recursive relationship is the basis of Q-learning.

\section{Tabular Q-learning}

When the state and action spaces are small, store one Q-value for every state-action pair in a table.

After observing transition $(s_t,a_t,r_{t+1},s_{t+1})$, update
\[
Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\left[r_{t+1}+\gamma\max_{a'}Q(s_{t+1},a')-Q(s_t,a_t)\right].
\]

The bracketed quantity is the \term{temporal-difference error}: the difference between the new target and the current estimate.

\begin{mlsteps}
  \item Initialize the Q-table, often with zeros.
  \item Observe the current state.
  \item Choose an action using an exploration strategy such as $\varepsilon$-greedy.
  \item Perform the action and observe reward and next state.
  \item Update the chosen Q-table entry.
  \item Repeat over many episodes, gradually reducing exploration when appropriate.
\end{mlsteps}

\begin{workedexample}
Suppose $Q(s,a)=2$, reward $r=1$, $\gamma=0.9$, the best next-state Q-value is $4$, and $\alpha=0.5$. The target is $1+0.9(4)=4.6$. The temporal-difference error is $4.6-2=2.6$. The update gives
\[
Q(s,a)\leftarrow2+0.5(2.6)=3.3.
\]
The estimate moves halfway toward the new target.
\end{workedexample}

\begin{analogy}
You believed the journey to school takes 20 minutes. Today it took 26. You do not now believe it takes 26 minutes -- one bad day is not the truth -- but you do not keep saying 20 either. You settle on something like 21. The learning rate $\alpha$ is how much you let a single experience change your mind, and $\gamma$ is how much you care about consequences that arrive later rather than immediately.
\end{analogy}

Too little exploration can trap the agent in a poor policy. Too much exploration wastes reward and may be unsafe.

\section{Evaluation and responsible use}

RL evaluation is harder than ordinary prediction because the policy changes the data it experiences. Use repeated runs with different random seeds and report both average return and variation.

Important concerns include:

\begin{itemize}
  \item reward design that accidentally encourages unwanted behavior;
  \item unsafe exploration in physical, medical, financial, or public systems;
  \item changing environments that make past experience unreliable;
  \item delayed rewards that make credit assignment difficult;
  \item simulation assumptions that do not match the real world.
\end{itemize}

For high-stakes applications, exploration should occur in a safe simulator or under strict constraints before real-world use.

\begin{keyidea}
Reinforcement learning does not learn from a correct answer for every action. It learns from consequences, balancing immediate reward, future reward, and the need to explore.
\end{keyidea}

\section{Bandit exploration behavior}

\begin{keyidea}
Look at the pull counts. The agent spent almost all its attempts on the best machine but never stopped sampling the others entirely. A fixed 10\% of decisions use a random exploratory action; some of those random actions still choose the current best arm. Continued exploration reduces the risk of settling early on the wrong answer, at the cost of occasionally taking an action believed to be worse.
\end{keyidea}

\begin{pitfall}
In a continuing task, an undiscounted infinite sum may be undefined, so the discounted formulation normally uses $\gamma<1$. Episodic tasks with guaranteed finite termination can permit $\gamma=1$. A fixed nonzero $\varepsilon$ deliberately keeps exploring; that may waste reward in a stationary deployment, but can remain useful in a changing environment. Evaluate the exploratory behavior separately from the greedy policy.
\end{pitfall}

\begin{keyidea}
Tabular Q-learning needs one table cell per state-action pair. For very large or continuous state spaces, the table cannot exist. Replacing it with a function approximator, sometimes a neural network that estimates $Q(s,a)$, leads toward deep reinforcement learning (\hyperref[ch:next]{the Epilogue}).
\end{keyidea}

\begin{chapterrecap}
\begin{itemize}
  \item An agent observes a state, takes an action, receives a reward, and moves to a new state.
  \item Return is the discounted sum of future rewards.
  \item $V(s)$ values a state; $Q(s,a)$ values an action in a state.
  \item Tabular Q-learning moves an old estimate toward reward plus discounted best future value.
  \item Exploration is necessary for learning but must be controlled for safety.
\end{itemize}
