# Build and preview performance

Tinymist previews update on typing without exporting a PDF on each save. Megamist also provides a live preview command; see the setup guide for its currently documented limitations.

Official CLI builds are single-pass. The scripts print elapsed time for each course. Detailed drawings are stored as SVG, and reusable flows use pinned, bundled Fletcher components. Font and package discovery does not require network access.

Run `.typst-setup/windows/step04-build-all.bat` or `sh .typst-setup/unix/step04-build-all.sh` after shared changes. Step 06 removes disposable output from `.build`.
